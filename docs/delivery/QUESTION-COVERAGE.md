# Morris collaborator questions: native workflow and exported evidence

Reference: supplied **Análise dos dados Morris.pdf**, pages4–5, inspected as text only. The PDF describes DORIS exports named COORD, DIST, PATH, PCOORD, DENSI, AREA RESULT and AREA TIME, followed by manual spreadsheet transfer and Save/Open Project. Its2min≈1800frames is an example15fps assumption. This app uses each source's actual metadata and verified frame/time contract; it never assumes15fps. Original DORIS/GPL attribution is preserved.

Open **Whole-study report → Select all contexts → Preview selected frozen study → Publish frozen HTML CSV and input**. Publication writes the complete selected-context inventory once, with immutable input/report JSON and a hash manifest. Do not copy scalar numbers by hand: open/import the CSVs. `GROUP_SCALARS_pt-BR.csv` uses semicolon delimiters and decimal commas; standard CSV uses comma delimiters and invariant decimal points. UTF-8/locale selection in Excel's Data→From Text/CSV avoids replacing commas manually. Empty numeric cells mean held/unavailable, not zero.

## First use with30 recordings and multiple groups

If no expected plan exists, the report shows an actionable checklist and **Create expected study plan**, opening the existing Experiment editor. Assign actual animal IDs/groups and expected repeats/missing slots; enter phase/day/order, release-relative window/bins, current tracking inspection and normalized source reference. Confirm these local inputs only after checking them, save reviewer/reason, reload report contexts and preview. Files are not biological animal N. Unknown inputs stay editable and hold dependent endpoints. Real scientific validation/researcher sign-off is deferred for collaborator testing; it is not a reason to make the supported local workflow unavailable.

Blinding uses opaque animal/trial/context/allocation aliases, hides destination path and authored reasons, and requires audited metadata reveal. Original pixels are unredacted. Exported plots are numerical SVGs; original private video pixels are not embedded. Missing/excluded/unreviewed cases stay in trial CSV/report and denominators. Historical reports before this projection retain their original four payloads and an explicit “recompute for question exports” notice; no historical values are fabricated.

This matrix describes software coverage and synthetic testing, not real tracking accuracy, clinical/learning inference or clean-Windows certification. Measured cm requires the separately supported calibration adapter and independent checks; this whole-study projection intentionally uses normalized pool diameters/radii, pixels and seconds.
